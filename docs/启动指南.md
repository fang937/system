# 启动指南

从零把系统跑起来。上面是「最快路径」，下面是每一步的细节与排错。

---

## 0. 三部分组成

| 部分 | 技术 | 地址 |
|---|---|---|
| 数据库 | MySQL 8 | 系统服务，不占浏览器 |
| 后端 | Spring Boot 3.5（Java 17+） | <http://localhost:8080> |
| 前端 | Vue 3 + Element Plus（Vite） | <http://localhost:8089> |

启动顺序：**数据库 → 后端 → 前端**。

---

## 1. 最快路径（3 条命令）

```bash
cd D:\software-work\system
cp .env.example .env          # 然后把 MYSQL_ROOT_PASSWORD 改成你的 MySQL 密码
./scripts/dev.sh              # Windows PowerShell: powershell -ExecutionPolicy Bypass -File scripts\dev.ps1
```

启动后浏览器打开 <http://localhost:8089>，用演示账号登录即可。

首次启动会自动完成：建库（若不存在）→ 建 12 张表（`schema.sql`）→ 写入真实名册（6 个实训室 / 25 位导师）+ 演示学生（8 名，学号 2023001~2023008）。
`users` 表非空时不会重复写入。

---

## 1.1 Docker 方式（换机器、答辩演示最省事）

前置：装好 Docker Desktop 并**保持运行**（托盘里的鲸鱼图标是绿的）。

```bash
cd D:\software-work\system
cp .env.example .env                     # 填 MYSQL_ROOT_PASSWORD
docker compose up -d --build             # 首次会构建镜像，几分钟
docker compose ps                        # 三个容器都应为 running / healthy
```

访问 <http://localhost:8089>。

- 三个容器：`labselect-mysql`（3306）、`labselect-backend`（8080）、`labselect-frontend`（8089→80）。
- 前端 Nginx 已把 `/api` 反代到后端容器，无需额外配跨域。
- 数据存在 `labselect-mysql-data` 卷里，`docker compose down` 不会丢；`down -v` 才会清空并重新初始化演示数据。
- 端口冲突（本机 MySQL 已占用 3306）时，在 `.env` 里把 `MYSQL_PORT` 改成 3307 即可，容器内不受影响。
- 构建需要联网拉 Maven / npm 依赖；国内网络可用 `.env` 里的 `NPM_REGISTRY=https://registry.npmmirror.com`。

常用命令：

```bash
docker compose logs -f backend     # 后端日志（含演示数据初始化输出）
docker compose restart backend     # 重启后端
docker compose up -d --build       # 改代码后重建
docker compose down                # 停止（保留数据）
```

> 注意：本机 Docker 守护进程未启动时，`docker compose` 会报 `cannot find the file specified ... dockerDesktopLinuxEngine`，先打开 Docker Desktop 再执行。

## 2. 手动启动（不用脚本）

### 2.1 数据库

```bash
# 建库 + 建表（也可跳过，后端启动时会自动建库建表）
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p你的密码 < backend\src\main\resources\schema.sql
```

默认库名 `lab_select_v2`。

### 2.2 后端

```bash
cd backend

# 环境变量方式（推荐）
DB_HOST=127.0.0.1 DB_PORT=3306 DB_NAME=lab_select_v2 DB_USER=root DB_PASSWORD=你的密码 \
  mvn spring-boot:run

# 或先打包再运行
mvn -DskipTests package
java -jar target/lab-select.jar
```

成功标志：

```
Tomcat started on port 8080 (http)
Started LabSelectApplication in 2.x seconds
实训室名册就绪：6 个实训室 / 25 位导师 / 总名额 382
当前轮次：1，活跃阶段：意向填报
```

验证：<http://localhost:8080/api/health> 返回 `"status":"UP"`。

### 2.3 前端

```bash
cd frontend
npm install          # 首次
npm run dev -- --port 8089
```

`vite.config.js` 已把 `/api` 代理到 `127.0.0.1:8080`，浏览器同源，无跨域问题。

## 4. 走一遍完整流程（约 5 分钟）

演示数据默认停在「第 1 轮 · 意向填报」，管理端可以随时跳阶段。

1. **学生填报**：`2023001` 登录 → 「我的志愿」→ 选 2~3 位导师、勾选服从调剂 → 提交。
2. **进入面试**：`admin` → 「阶段与轮次」→ 找到「面试与初选（第 1 轮）」→ 点「立即进入」。
3. **导师打分**：`liuguanjun`（或任一导师账号）登录 → 「报考我的学生」→ 给该学生打分 → 处置选「拟录取」→ 保存。
   - 名额只有 2 个，第 3 个人点拟录取会被拒绝——这就是防超卖。
   - 多余的人可以标「递补」，系统自动排顺位。
4. **进入确认**：`admin` → 「拟录取确认（第 1 轮）」→「立即进入」。
5. **学生确认**：`2023001` → 「我的 Offer」→ 接受 → 「录取结果」能看到导师与实训室。
6. **超时递补**（可选）：把某条待确认 Offer 的截止时间改到过去，等 30 秒，定时任务会把名额释放并顺位递补给下一位。
7. **统筹调剂**：`admin` → 「统筹调剂」→「执行全院调剂」→ 调剂池按优先级自动匹配。
8. **导出**：`admin` → 「结果公示」→「导出 Excel」。

## 5. 常见报错

| 报错 | 原因 | 处理 |
|---|---|---|
| `Access denied for user 'root'@'localhost'` | `.env` 密码不对 | 改 `MYSQL_ROOT_PASSWORD` |
| `Communications link failure` | MySQL 没启动 | 服务里启动 `MySQL80` |
| `Port 8080 was already in use` | 端口被占 | 关掉占用进程，或 `--server.port=8081` |
| 页面空白 / 接口 404 | 后端没起来 | 先确认 `/api/health` 能打开 |
| 登录提示账号或密码错误 | 演示数据没写入 | 确认 `DEMO_DATA=true` 且 `users` 表为空 |
| 按钮全灰、提示「当前不在 xx 阶段」 | 阶段窗口不覆盖当前时间 | 管理端「阶段与轮次」→「立即进入」 |
| `npm install` 卡住 | 官方源慢 | `npm config set registry https://registry.npmmirror.com` |
| Java 版本报错 / Lombok 不生效 | JDK 过新或过旧 | 用 JDK 17~21；本仓库已显式声明 Lombok 注解处理器 |
| `cannot find the file specified ... dockerDesktopLinuxEngine` | Docker Desktop 没启动 | 打开 Docker Desktop，等鲸鱼图标变绿再执行 `docker compose` |
